## 本次实现

- Rust workspace，固定 Rust 1.99.0、tsclientlib commit 与 Cargo.lock。
- Tauri 2 + React/TypeScript 桌面壳，包含连接表单、真实状态、频道树、可见用户和当前频道消息界面。
- 独占协议连接的后台任务，有界命令队列、watch 快照和 broadcast 事件。
- 地址/昵称验证、连接、同步阶段、频道/用户快照、断开、30 秒初次连接期限、临时重连状态与终止错误处理。
- 等待频道列表完成且自身所在频道可见后才发布“已连接”，避免握手成功时出现空频道树。
- 当前频道消息发送/确认接口，10 秒确认超时，断线时不自动重发；接收只转发频道消息，不混入私聊。
- OS keyring 默认身份读写与等级更新接入；临时身份须明确选用，凭据存储失败不退回明文。系统凭据实际交互还需单独验收。
- 无自动发言/消息的协议 CLI，密码从 stdin 读取，支持限时观察和 JSON 快照。
- CPAL 设备枚举；48 kHz/10 ms 帧累积器；RNNoise（nnnoiseless）和 WebRTC APM NS/AEC/AGC 的独立处理封装。
- 三端核心/桌面 CI 配置与 macOS/Linux WebRTC 构建配置；本次没有推送或执行远程 CI。
