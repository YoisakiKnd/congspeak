## 实施顺序

1. 日常交互：频道、分目标聊天、用户动作、收藏、个人音量和屏蔽。
2. 本地数据：多身份、收藏分组、联系人、历史、导入导出与配置迁移。
3. 服务器资源：频道管理、头像/图标、文件管理与后台传输任务。
4. 权限和管理：权限数据模型、查询/修改、组成员、封禁、密钥和日志。
5. 高级语音：Whisper、Talk Power/强制 PTT、录音、位置和音频配置。
6. 多连接和桌面：多服务器路由、托盘/快捷键/通知/深链接/主题/更新。
7. TS3 对照验收：逐操作核对实际 TS3 客户端，三端真机、人声互通、异常恢复、长时间运行和安装验证。

当前未完成整体功能对齐。不可将未实现项标为完成，测试版也不可宣传为 TS3 完全替代品。

## 0.5.0 原生版交付范围（2026-11-18）

- 原生版频道右键菜单提供频道管理和文件入口，涉及删除与封禁的操作需在客户端确认。服务器决定权限与操作结果。
- 文件传输具有本地进度、取消和断线停止。下载先写目标目录中的临时文件，完成后保存，拒绝覆盖已存在的目标。上传默认拒绝覆盖远端同名文件。取消或中断的上传可能在服务器留下残留文件。
- 授权服务器的空目录读取通过。文件内容传输的长度和提前结束处理已通过自动测试。该服务器未执行上传、删除、封禁或频道修改。

## 0.5.2 原生版补充

- 新建与导入的身份独立保存至系统凭据库。已有默认身份沿用原来的条目。收藏仅引用本机身份，跨设备导入收藏后需重新选用身份。TS3 身份通过单独的 INI 文件导入导出，文件含私钥。
- 从「管理」打开服务器封禁列表，确认后可按封禁编号解除。在线用户详情可提交投诉。服务器确认后界面才更新结果，错误显示服务器返回的原因。
- 针对 TS3 INI 的 UID 与安全等级、封禁列表中含 IP 模式和多条记录的解析已增加自动检查。Windows 真机及有权限的管理操作仍待验收。
